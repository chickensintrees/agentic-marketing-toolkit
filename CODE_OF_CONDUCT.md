# Code of Conduct

This project is built by a class of people learning together, many of them for
the first time. We want it to be welcoming, respectful and harassment-free for
everyone.

We adopt the **Contributor Covenant, version 2.1**, as our code of conduct:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short:

- Be kind and patient. Everyone here is learning, and questions are welcome.
- Critique the work, not the person. Assume good intent.
- No harassment, discrimination, insults or personal attacks.
- Respect privacy. Don't post anyone's personal information.
- The same standards apply to anything your coding agent writes in your name.

## Reporting

If something here makes you uncomfortable, contact the maintainer, Bill Moore,
privately: in person, through the course, or through his GitHub profile
(https://github.com/chickensintrees). You can also use GitHub's **Report
content** option on a comment. Reports are handled in confidence.

## Enforcement

The maintainer may edit or remove comments, close issues or pull requests, or
block contributors who don't follow this code, following the Contributor
Covenant's enforcement guidelines.
