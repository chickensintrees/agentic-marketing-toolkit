# Replit Agent instructions

Before doing anything else, read and follow **AGENTS.md** in this folder. It is
this project's playbook: rules, commands, and the student onboarding protocol.
Then read **SPEC.md** (the source of truth) and **CONTRIBUTING.md**.

- Commands: `npm install`, `npm run dev`, `npm run check` (the definition of done).
- Push only to a repository the student owns. Work in the student's **fork**, then open the pull request against `chickensintrees/five-forces-explorer`. Ask the student before you push or open a pull request.
- Keep this file short and do not rewrite it. Do not rewrite AGENTS.md or CLAUDE.md either. Keep Replit-specific setup changes out of pull requests unless the PR is about them.
