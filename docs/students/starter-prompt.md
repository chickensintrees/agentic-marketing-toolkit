# Starter prompt

Copy everything in the box and paste it into your coding agent as your first
message. [Start here](START-HERE.md) explains what you need first.

```text
Help me get set up to contribute to our class project: github.com/chickensintrees/agentic-marketing-toolkit. Read AGENTS.md and follow it. Walk me through connecting you to my GitHub account (browser sign-in only), forking the project, and running it. I'm new to this, so explain each step and ask me before anything public.
```

The prompt is short because the project's `AGENTS.md` gives your agent the
detailed steps. Once the app is running, your agent offers you three first
issues, then helps you plan, check and submit your change as a pull request.
