## Want to contribute? Paste this into your coding agent

Use any one: Codex, Claude Code, Cursor, Replit or Lovable. Copy the prompt
exactly:

```
I'd like to contribute to an open-source class project:
https://github.com/chickensintrees/five-forces-explorer

I'm new to coding, so explain each step in plain language as we go.

1. Read the project's README.md, AGENTS.md, and docs/students/START-HERE.md, and follow the instructions in AGENTS.md.
2. Tell me what the project does and how contributing works.
3. Check whether you can reach GitHub for me. Don't assume you can. If I need to sign in or approve access, walk me through it.
4. Help me make my own copy (a fork) and get the app running. Ask me before you fork, push, or open a pull request.
5. Suggest three small first contributions from docs/students/first-issues.md and let me pick one.
6. Before writing code, show me a short plan, and update SPEC.md first if the change alters how the app behaves.
7. Run npm run check and show me the result before we commit.
```

## What you approve yourself

The agent does the typing. **You** make these decisions:

- Signing in to GitHub, and any access the agent asks for.
- Making your fork (your own copy of the project).
- The plan, before any code is written.
- Every push and every pull request.

If the agent tries to do one of these without asking, tell it to stop and
ask first.

## Getting help

Stuck, confused, or not sure what to pick? Open an **issue** on the project
using the **"question"** template: go to the project page, then
**Issues → New issue → question**. Bill will answer. No question is too
basic.

## Is this required?

**No. Contributing is voluntary unless your instructor assigns it.** Bill is
happy to help anyone who wants to try.
